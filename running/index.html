🏃 Running in Houston

A run club for most nights of the week, and the races worth putting on a calendar. I run with Sexy Pace on Wednesdays. All of these are open — turn up, run your own pace, leave when you want.

The week

  • Mondays 🏃 Heavy Hitters Run Club @heavyhittersrunclub — this week's run goes up on their page.
  • Mondays 🏃 iRUN.HTX @irun.htx — the other Monday option, if you want a second one.
  • Tuesdays 🏃 Space City Run Club @spacecityrunclub — details and meeting spot go up on their page.
  • Wednesdays, 7PM · my club 🏃 Sexy Pace Running Club Hermann Park, at Miller Hill by the Reflection Pool. Free, every pace, groups for all of them — walk-jog included. This is the one I run with. Check in on their site when you get there.
  • Thursdays 🏃 Everyday Hustle Run Club @everydayhustlerunclub — weekly run posted on their page.
  • Fridays 🏃 Pushing Paces Run Club @pushingprunclub — ending the week on your feet.

Crews worth knowing

These don't sit on one fixed weeknight — check their pages for what's coming up.

  • 🏃 Revival Run Crew @revivalruncrew — a lesbian run crew in Houston.
  • 🏃 Krisathon @krisathon — in their own words, Houston's LGBT and beginner-friendly run club. A good first one if you've never done a group run.

Not a run, same people

  • ☕ Coffee & Perreo @coffee_perreohtx — a Houston day party. Dates go up on their page.
  • 📱 @ismael_run_tech Where I post which of these I'm actually at, and the races I'm training for.

Check before you go. Run times and start lines move, so Instagram and each race's own page are always more current than this one. Know a Houston race or group run that belongs here? Tell me.
